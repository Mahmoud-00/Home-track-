# HomeTrack — تتبّع أصناف البيت

تطبيق ويب عربي متجاوب لتسجيل مشتريات أصناف المنزل، وتاريخ نفاد كل عبوة، ومتوسط مدة الاستخدام، ومتوسط الاستهلاك اليومي، وموعد النفاد المتوقع.

## تجربة سريعة

افتح `index.html` في المتصفح. من دون إعداد Supabase، يعمل التطبيق في **الوضع المحلي التجريبي** ويحفظ البيانات في المتصفح الحالي فقط. لا تخلط بين الوضع المحلي والمزامنة السحابية: بيانات المتصفح لا تنتقل تلقائيًا إلى جهاز آخر.

## تفعيل الحساب والمزامنة بين الأجهزة

1. أنشئ مشروعًا في Supabase.
2. افتح **SQL Editor** في لوحة مشروعك، والصق محتويات `schema.sql` ثم نفّذها.
3. من إعدادات المشروع انسخ **Project URL** و **anon/publishable key**. لا تستخدم `service_role` key في واجهة المتصفح.
4. افتح `config.js` وضع القيم:

   ```js
   window.HOMETRACK_CONFIG = {
     SUPABASE_URL: "https://YOUR-PROJECT.supabase.co",
     SUPABASE_ANON_KEY: "YOUR-PUBLISHABLE-OR-ANON-KEY"
   };
   ```

5. في إعدادات Authentication، اضبط عنوان الموقع وعناوين إعادة التوجيه وفق عنوان الاستضافة الذي ستستخدمه. إذا كان تأكيد البريد مفعّلًا، أكّد البريد قبل تسجيل الدخول.
6. ارفع ملفات المشروع إلى مستودع GitHub، ثم انشره باستخدام استضافة مواقع ثابتة مثل GitHub Pages. ارفع الملفات الخمسة: `index.html`, `style.css`, `app.js`, `config.js`, `schema.sql` (ويمكنك إبقاء README).
7. افتح الرابط وسجّل حسابك. استخدم الحساب نفسه على الكمبيوتر والموبايل للمزامنة.

## طريقة الحساب

- مدة العبوة المكتملة = تاريخ النفاد − تاريخ الشراء بالأيام.
- متوسط المدة = متوسط مدد العبوات المكتملة للصنف.
- متوسط الاستهلاك اليومي = مجموع كميات العبوات المكتملة ÷ مجموع أيام استخدامها، ويظهر بنفس وحدة القياس المختارة للصنف لكل يوم.
- النفاد المتوقع للعبوة الحالية = الكمية الحالية ÷ متوسط الاستهلاك اليومي، محسوبًا من السجلات المكتملة السابقة.
- إذا لم توجد عبوة مكتملة بمدة موجبة، سيعرض التطبيق أن البيانات غير كافية للتنبؤ.

## التنبيهات

النسخة الحالية تعرض تنبيهات داخل لوحة التطبيق عند اقتراب موعد النفاد المتوقع (ثلاثة أيام أو أقل). إشعارات المتصفح/الهاتف عندما يكون التطبيق مغلقًا ليست مفعّلة في هذه النسخة.

## ملاحظات مهمة

- بيانات الوضع المحلي محفوظة في المتصفح الحالي فقط؛ صدّر نسخة احتياطية من زر التصدير بانتظام.
- النسخ الاحتياطي JSON يمكن استيراده من زر الاستيراد. الاستيراد يستبدل السجلات الحالية.
- لا تضع أي مفتاح سري أو `service_role` key داخل ملفات الواجهة.
- هذه نسخة أولية عملية؛ اختبرها بسجلات تجريبية قبل الاعتماد عليها للاستخدام الطويل.
